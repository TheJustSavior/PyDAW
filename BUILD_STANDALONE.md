# Сборка standalone версии PyDAW

Этот документ описывает процесс создания автономной версии PyDAW, которая может работать на любом компьютере без установленного Python.

## Требования для сборки

- Python 3.10+ установлен на компьютере разработчика
- PyInstaller установлен: `pip install pyinstaller`
- Проект собран и модуль `pydaw_engine.cp314-win_amd64.pyd` присутствует в папке `pydaw/`

## Процесс сборки

### Автоматическая сборка

Запустите скрипт сборки:

```powershell
cd F:\Dev\CursorProjects\PyDAW
py build_exe.py
```

Или используйте батник:

```powershell
.\build_standalone.bat
```

### Результат сборки

После успешной сборки исполняемый файл будет находиться в:
```
F:\Dev\CursorProjects\PyDAW\dist_pyinstaller\PyDAW\PyDAW.exe
```

Вся папка `PyDAW` содержит:
- `PyDAW.exe` - главный исполняемый файл
- `_internal/` - папка с библиотеками и зависимостями (Python DLL, PySide6, numpy, soundfile и т.д.)

## Тестирование сборки

Перед публикацией обязательно протестируйте:

```powershell
.\dist_pyinstaller\PyDAW\PyDAW.exe
```

Проверьте:
1. Приложение запускается без ошибок
2. Можно создать новый проект
3. Можно загрузить аудиофайлы
4. Воспроизведение работает
5. Можно сохранить и загрузить проект
6. Экспорт в WAV работает

## Распространение

### Создание архива для релиза

```powershell
cd dist_pyinstaller
Compress-Archive -Path "PyDAW" -DestinationPath "PyDAW-v0.1.1-Windows-x64.zip" -Force
```

### Размер дистрибутива

- Папка `PyDAW`: ~250-300 МБ (распакованная)
- ZIP-архив: ~80-100 МБ

## Техническая информация

### Что включено в сборку

- Python 3.14 runtime (`python314.dll`)
- PySide6 (Qt6) - полный набор библиотек
- NumPy и его зависимости
- SoundFile для работы с аудио
- C++ модуль `pydaw_engine` (аудио-ядро)
- VST3 host (`pydaw_vst_host.exe`)

### Известные ограничения

1. Сборка специфична для Windows x64
2. Требуется Visual C++ Redistributable (обычно уже установлен в Windows 10/11)
3. Первый запуск может быть медленнее из-за инициализации Qt

### Решение проблем

**Ошибка "Failed to load Python DLL":**
- Убедитесь, что используется правильная точка входа (`run_pydaw.py`, а не `pydaw/app.py`)
- Пересоберите с помощью `py build_exe.py`

**Ошибка "ImportError: attempted relative import":**
- Это происходит при неправильной точке входа
- Используйте `run_pydaw.py` как entry point

**Приложение не запускается без ошибок:**
- Проверьте наличие Visual C++ Redistributable
- Запустите из командной строки для просмотра ошибок

## Обновление версии

При создании новой версии:

1. Обновите версию в `pyproject.toml`
2. Пересоберите C++ модуль: `pip install -e . --no-build-isolation`
3. Пересоберите standalone версию: `py build_exe.py`
4. Протестируйте новую сборку
5. Создайте новый архив с новым номером версии

## Структура файлов сборки

```
dist_pyinstaller/
└── PyDAW/
    ├── PyDAW.exe                    # Главный исполняемый файл
    └── _internal/                   # Внутренние файлы (не трогать)
        ├── python314.dll            # Python runtime
        ├── pydaw/                   # Модули PyDAW
        │   ├── pydaw_engine.pyd     # C++ аудио-ядро
        │   └── pydaw_vst_host.exe   # VST3 host
        ├── PySide6/                 # Qt библиотеки
        ├── numpy/                   # NumPy
        └── [другие библиотеки]
```

## Альтернативные способы сборки

### Сборка в один файл (не рекомендуется)

Можно создать один большой EXE файл, изменив в `build_exe.py`:
```python
'--onefile',  # вместо '--onedir'
```

Минусы:
- Медленный запуск (распаковка во временную папку)
- Больше проблем с антивирусами
- Сложнее отладка

Рекомендуется использовать `--onedir` (по умолчанию).
