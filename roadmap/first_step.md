# Первый шаг: что уже сделано

Состояние проекта на момент завершения этапов 1–5 из [PLAN.md](../PLAN.md).
Всё собрано, протестировано и запускается: `python -m pydaw.app`.

## Архитектура (кратко)

- **Python (PySide6)** — интерфейс и модель проекта. **C++ (`pydaw_engine`)** — всё аудио в реальном времени.
- Аудиопоток C++ никогда не вызывает Python. Python шлёт команды через lock-free очередь (`ring_buffer.h`), ядро отдаёт позицию/уровни через атомики; UI опрашивает их QTimer'ом ~60 Гц.
- Сборка: scikit-build-core + pybind11 + CMake (`pip install -e . --no-build-isolation`). RtAudio **6.0.1** (master несовместим — namespace `rt::audio`), dr_libs для декодирования.

## C++ ядро — `engine/src/`

| Файл | Что делает |
|---|---|
| `audio_engine.cpp/.h` | RtAudio/WASAPI устройство (48 кГц, 512 сэмплов), транспорт play/pause/seek, очередь команд `Command`, кэш файлов, офлайн-экспорт WAV (float32) |
| `mixer.cpp/.h` | Дорожки/клипы, gain + constant-power pan, mute/solo, суммирование, tanh-лимитер, атомарные пик-метры. Интерфейс `EffectSlot` — задел под VST3 |
| `audio_file.cpp/.h` | Декодирование WAV/FLAC/MP3/AIFF (dr_wav/dr_flac/dr_mp3), линейный ресэмплинг к частоте устройства, стерео float32 в памяти, min/max-пики для волновых форм |
| `bindings.cpp` | pybind11: класс `AudioEngine` со всем API (load_file, add_clip, play, export_wav...) |

Владение файлами: `AudioFilePtr` (shared_ptr) едет внутри команды `AddClip`, аудиопоток не трогает мьютекс кэша.

## Python — `pydaw/`

| Модуль | Что делает |
|---|---|
| `engine_bridge.py` | Единственная точка доступа к ядру + `_StubEngine` (тихий фоллбэк, если модуль не собран) + кэш пиков |
| `model/project.py` | `Project/Track/Clip`, JSON-сериализация (`.pydaw`), `next_id()`/`bump_id_counter()` |
| `model/commands.py` | `Command` (do/undo) и `UndoStack` |
| `ui/main_window.py` | Связывает всё: меню, undo/redo, drag&drop → клипы, транспорт, загрузка/сохранение проекта, экспорт |
| `ui/timeline.py` | `TimelineView` (QGraphicsScene): ленты дорожек, линейка, сетка, курсор, зум Ctrl+колесо, клик = seek, приём drag&drop |
| `ui/clip_item.py` | Клип: прямоугольник с волновой формой (QPixmap-кэш), перетаскивание по времени |
| `ui/track_header.py` | Панель дорожек: имя, M/S, фейдер, панорама, пик-метр, кнопка добавления |
| `ui/transport_bar.py` | Play/Stop, тайм-дисплей, мастер-громкость, мастер-метр |
| `app.py` | Входная точка (`python -m pydaw.app`, gui-script `pydaw`) |

## Проверено (tests/test_engine.py — проходит)

- Загрузка WAV 44,1 кГц → ресэмплинг к 48 кГц (1 с ≈ 48000 фреймов).
- Peak-кэш отражает амплитуду сигнала.
- Сохранение/загрузка проекта (roundtrip).
- Офлайн-экспорт микса: длина точно = позиция клипа + его длительность.
- GUI стартует, аудиоустройство инициализируется, закрывается с кодом 0.

## Известные особенности / нюансы

- `python` в PowerShell этой машины — заглушка Windows Store; использовать полный путь `C:\Users\hotma\AppData\Local\Programs\Python\Python314\python.exe`.
- Экспортируемый WAV — float32: стандартный модуль `wave` его не читает (ядро читает).
- Ресэмплинг линейный — для качества можно позже заменить на libsamplerate.
- Обрезка (trim) клипов в UI не реализована (в модели/ядре `source_offset`/`length` уже есть).
- Фейдеры/панорама не пишутся в undo-стек (непрерывные контролы), это осознанно.
